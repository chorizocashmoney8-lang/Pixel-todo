# PRD · Pixel Todo 桌面版

状态:第二轮改版实施基准(2026-11-02,用户已批准进入实施)。未在“用户已确认”中列出的细节是实现默认值,不是用户逐项指定。

## 1. 产品目标

Pixel Todo 是个人使用的 Windows 桌面待办与番茄钟。软件常驻桌面角落,轻量呈现近期任务;完整窗口提供待办、专注计时、统计和设置。数据仅保存在本机。

## 2. 目标与非目标

目标:
- 快速查看与维护任务,记录学习专注;关闭完整窗口后仍可从小窗口或托盘恢复。
- 以像素风、七套主题、对应像素小人和像素字体构成一致界面。
- 自然到点时提供视觉与声音提醒;空闲和隐藏时保持低资源占用。

非目标:
- 账号、云同步、多设备、手机/网页客户端。
- 精确到时分的任务截止时间,或番茄钟与任务的强制关联。
- 将用户导入的音频上传或分享;音频只在本机使用。

## 3. 待办

- 添加、编辑、完成、筛选(全部/未完成/已完成/回收站)、删除、撤销、恢复、彻底删除及清空回收站。
- 任务字段:名称、优先级(高/中/低)、可选截止日期(仅日期)。排序按优先级、截止日期、创建顺序。
- 删除项保留7天后自动清理。名称按纯文本显示。
- 继续支持快捷添加、键盘操作、日期提示和小窗口任务摘要。

## 4. 番茄钟与统计

- 学习段25分钟、休息段5分钟;可开始、暂停/继续、放弃当前段、立即完成、跳过休息。
- 自然走完25分钟或用户点“立即完成”都计1次并进入5分钟休息;放弃不计数。记录区分自然完成与手动完成,不把手动完成表述为完整专注25分钟。
- 休息自然结束回到待开始。手动完成不触发自然到点提醒(沿用原有主动操作不提醒的行为,作为本轮实现默认)。
- 统计今天、本周、全部次数,按学习内容汇总并展示最近记录。

## 5. 小窗口、完整窗口与视觉

- 完整窗口使用无系统标题栏的一体化顶部栏,包含页面切换、收起和隐藏;去掉背景方格。布局以已验收的完整窗口原型为基准,初始窗口约900×626。
- 小窗口固定在屏幕角落,显示最多2条未完成任务、计时状态和小人气泡;宽度开启小人/对话时248px,关闭时216px。点击展开完整窗口;完整窗口打开时小窗隐藏,收起后恢复。小窗右上角“×”可暂时隐藏到系统托盘;番茄钟到点时小窗重新出现,或用户从托盘打开完整窗口后,之后收起完整窗口时小窗重新出现。
- 小窗默认不置顶,可在设置中开启;系统托盘菜单提供打开和退出。
- 七套主题与角色以 `docs/REDESIGN_V2_NOTES.md` 指定的 `themes-v3.html`、`buddies-v10.html` 为视觉源。默认主题A墨。默认使用 Fusion Pixel 12px Proportional SC;提供系统字体选项。
- 小人提供已确认的四种表情、两种手势,可固定选择或随机待机;可关闭小人及气泡。小人以简短自然的日常用语提示待办/陪伴,不朗读诗句。诗句仅作为完整窗口待办页上方的氛围文案;当前原型使用海子《面朝大海，春暖花开》的一句,后续可调整。
- 学习、休息和任务完成使用轻量像素动画;设置可关闭。窗口隐藏或应用处于后台时暂停动画及气泡轮换。

## 6. 提醒与声音

- 自然到点弹出软件自有像素提醒,按当前主题配色并显示小人;弹窗持续到用户确认。托盘图标慢闪10秒,确认后停止。
- 自然完成学习段时播放所选声音一次。默认音效为已选定的原创合成“通关加长版”(约2.61秒);提供3种内置柔和复古电子音、音量调节和本地音频导入。避免尖锐或写实音效。
- 提醒弹窗确认即停止当前声音和托盘闪烁。应用退出或状态变化不得造成重复播放。
- 默认音量25%沿用原型试听值;作为实施默认,在用户验收时可调整。

## 7. 设置与实现默认值

- 设置项:主题、字体、小人/气泡显示、固定/随机待机及表情/手势、动画开关、提示音/音量/导入、置顶、开机启动。
- 默认值:主题A、像素字体、显示小人、固定待机(淡定表情/手垂两侧)、动画开启、通关加长音、音量25%、不置顶、随机模式切换间隔8秒。
- 上述默认值来自当前原型或为保持原有行为所作的实现选择,后续可在验收时调整。

## 8. 成功标准

- 已保存的任务、计时记录和设置在应用重启后保留;旧版本数据升级不丢失。
- 小窗与完整窗口互相收放、托盘隐藏恢复稳定;提醒只按规则触发一次。
- 常驻空闲时CPU接近0;隐藏/后台时暂停动画与轮换。
- Windows安装包可正常安装、启动和卸载。

## 9. 数据迁移

第一版 JSON v3 数据升级到 v4。保留所有任务、番茄钟记录、运行中的计时和已有设置,为新增偏好填充默认值。旧浏览器版数据仍由用户手动重录,不做浏览器数据迁移。
